# Вариант 6
# Продажа продуктов в мире 

### Цель проекта — обработка и анализ данных о продажах продуктов в мире на основе CSV-файла с последующим сохранением данных в базу данных SQLite и выполнением аналитических SQL-запросов.

Проект реализован на языке Java с использованием Maven, SQLite и JDBC, xchart.

Архитектура проекта построена с разделением на слои, что соответствует принципам Clean Architecture.

#### Входные данные представлены в файле:
products.csv

## Запуск проекта

#### 1) Удаление старой базы данных если существует
del products.db


#### 2) Сборка проекта
mvn clean package

#### 3) Запуск приложения
java -jar target/products-sales-1.0.0.jar
